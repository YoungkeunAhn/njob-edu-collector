# 종합 결론

- 작성일: 2026-10-11
- 근거: [02-교육소스](../02-교육소스/00-START-HERE.md) 4개 영역, [03-데이터수집](../03-데이터수집/00-START-HERE.md)

## 1. 핵심 발견 7가지

1. **공공 무료 AI 교육은 "AI디지털배움터"(디지털배움터.kr) 하나로 모였다.**
   2026년부터 서울·경기·인천·부산·대구·광주·울산 등이 같은 누리집에 강좌를 올리고, 시도·시군구·읍면동 필터를 쓴다. 우리 서비스의 "지역 + 분야" 구조와 그대로 맞는다.
   다만 공식 API가 없다. 목록은 토큰 헤더가 붙은 내부 JSON으로 그려지기 때문에, 헤드리스 브라우저로 수집한다(확정).
   → [전국-AI디지털배움터.md](../02-교육소스/01-지자체-공공/전국-AI디지털배움터.md)
2. **국비 교육은 고용24 훈련과정 Open API 하나로 모두 받을 수 있다.**
   KDT·KDC·산대특·일반 내배카 과정이 모두 들어 있다. 패스트캠퍼스나 멀티캠퍼스 같은 민간기관 과정도 포함되므로 기관별로 따로 수집할 필요가 없다. 지역·NCS·훈련유형 필터를 지원한다.
   **걸림돌은 인증키다.** 기업회원만 신청할 수 있고 심사를 거친다.
   → [고용24-훈련과정-API.md](../02-교육소스/02-국비-내일배움카드/고용24-훈련과정-API.md)
3. **내일배움카드 과정은 2026년부터 자부담이 생겼다.**
   KDT·국기·산대특 과정이 대상이다(300만원 이하 과정은 10%, 그 이상은 30만~60만원 정액). AI 캠퍼스만 면제다. 가격 필드에 자부담액을 넣으면 된다.
   → [내일배움카드-제도.md](../02-교육소스/02-국비-내일배움카드/내일배움카드-제도.md)
4. **동네 평생학습 강좌는 전국평생학습강좌표준데이터(data.go.kr 15013110)로 한 번에 받는다.**
   분기마다 갱신되고 수강료·접수기간·주소 필드가 있다. 서울은 공공서비스예약 교육 API(`ListPublicReservationEducation`)로 보충한다.
   → [평생학습강좌-표준데이터.md](../02-교육소스/03-평생교육-온라인/평생학습강좌-표준데이터.md)
5. **주변애(greenlove.kr)는 AI 교육 사이트가 아니라 고양·일산 지역 커뮤니티다.**
   무료 AI 특강이 한 달에 1~2건 올라온다. 이런 "동네 무료 특강"은 전국 단위로 보면 **이벤터스(event-us.kr)**에 가장 많이 모인다. 이벤터스는 내부 검색 API가 JSON을 돌려주고, "바이브코딩" 검색만 254건이 나온다.
   단, 이벤터스 약관은 제3자 제공을 금지한다. 그래서 이벤터스를 수집할지는 미결이다.
   → [주변애-greenlove.md](../02-교육소스/04-민간-커뮤니티-모임/주변애-greenlove.md), [행사-이벤트-플랫폼.md](../02-교육소스/04-민간-커뮤니티-모임/행사-이벤트-플랫폼.md)
6. **N잡러에게 잘 맞는 강좌는 서울에 몰려 있다.**
   서울시평생학습포털(「생성형 AI활용 유튜브 쇼츠 크리에이터 양성과정」 등), 서울시50플러스재단(40세 이상), SeSAC(청년)이 대표적이다. 경기에서는 경기콘텐츠진흥원 AI 콘텐츠 캠퍼스가 AI 영상 분야에 가장 잘 맞는다.
7. **기업 CSR 아카데미와 유료 클래스 플랫폼은 우선순위가 낮다.**
   SSAFY·KT 에이블스쿨 같은 CSR 아카데미는 청년 취업용 장기 과정이다. 클래스101·탈잉 같은 클래스 플랫폼은 유료이고 목록이 JS로 그려진다. 온오프믹스·문토·창조경제혁신센터는 robots.txt로 수집을 막아 두었다.

## 2. 소스 우선순위 (MVP 기준)

> 조사한 소스 전체(막힌 곳 포함)의 수집 가능 여부와 포함 여부 결정 칸은 [소스별-수집가능성-목록.md](../03-데이터수집/소스별-수집가능성-목록.md)에 있다. 아래 표는 그중 우선순위가 높은 것만 추린 것이다.

| 순위 | 소스 | 비용 | 지역성 | 수집 방법 | 선결 조건 |
|---|---|---|---|---|---|
| 1 | 고용24 훈련과정 API | 내배카(자부담) | 시도·시군구 | **공식 Open API** | 기업회원 인증키. 키 발급 전에는 공개 검색 HTML 수집 |
| 2 | 전국평생학습강좌표준데이터 | 무료~소액 | 주소 기반 | **공식 Open API** (data.go.kr) | 활용신청(즉시) |
| 3 | AI디지털배움터 | 무료 | 시도·시군구·읍면동 | 헤드리스 브라우저 (**확정**) | — |
| 4 | 서울 공공서비스예약 교육 | 무료~소액 | 서울 자치구 | **공식 Open API** (서울 열린데이터) | 키 발급(즉시) |

## 3. MVP 제안 (최소 구성)

- **확정 사항 (2026-10-11)**
  - **1차 소스 목록 확정**: 판정이 ✅ 가능인 소스 16개와 디지털배움터를 1차 대상으로 정했다(수집 구현 전). → [소스별-수집가능성-목록.md](../03-데이터수집/소스별-수집가능성-목록.md) "1차 확정 목록"
  - **서비스 원칙: 링크 연결만 제공하고, 판단은 사용자가 한다.** 자격 판정·추천·신청 대행은 하지 않는다.
  - 디지털배움터는 헤드리스 브라우저로 수집한다.
  - 강좌마다 기간(교육 시작·종료일)과 가격을 넣는다.
  - 강좌 유형을 **원데이 클래스 / 교육훈련** 두 가지로 나눈다. 판정 규칙은 [수집-파이프라인-설계.md](../03-데이터수집/수집-파이프라인-설계.md) 3절에 있다.

- **수집**
  - 공식 API 3개(1·2·4번)와 K-MOOC로 시작한다. 법적 위험이 없고 키도 바로 받을 수 있다(고용24만 예외).
  - 디지털배움터는 헤드리스 브라우저로 수집한다(확정). 목록 페이지를 열고 내부 JSON 응답을 가로챈다.
  - 이벤터스는 수집 여부가 미결이라 MVP에서 뺀다.
- **저장**
  - `course` 테이블 1개에 `unique(source, source_id)`로 upsert한다.
  - 3일 연속 수집에서 빠지면 마감으로 처리한다.
  - → [수집-파이프라인-설계.md](../03-데이터수집/수집-파이프라인-설계.md)
- **지역**: 법정동코드 앞 5자리(시군구)를 쓴다. 고용24 지역코드는 이 체계와 달라서 매핑표가 필요하다.
- **카테고리**: 대분류 6개(AI 영상·이미지 / AI 코딩·바이브코딩 / 콘텐츠·블로그 수익화 / AI 커머스·마케팅 / 업무 자동화 / 생성형 AI 기초·활용)와 소분류 18개로 나눈다. 먼저 키워드 룰로 분류하고, 애매한 것만 LLM으로 분류한다.
  - → [카테고리-체계와-키워드.md](../03-데이터수집/카테고리-체계와-키워드.md)
- **표시**: 목록 정보(제목·기관·지역·기간·가격·유형)와 원문 링크·출처만 보여준다. 상세 내용 확인과 신청 여부 판단은 사용자가 원문 사이트에서 한다(서비스 원칙). 법적으로도 가장 안전한 방식이다.
  - → [크롤링-법적-이슈.md](../03-데이터수집/크롤링-법적-이슈.md)

## 4. 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| 고용24 인증키가 기업회원 전용이고 심사를 거침 | 1순위 소스가 늦어짐 | 사업자등록을 먼저 하고, 그동안 공개 검색 HTML 수집으로 버틴다 |
| 디지털배움터 화면·API 구조 변경 | 수집이 끊김 | 수집 건수 급감 알림으로 바로 감지한다 |
| 민간 플랫폼 약관(이벤터스 13조 등) | 민사 배상 위험(여기어때 10억 원 판결 참고) | 수집 여부 미결 — 결정 전에는 수집하지 않는다 |
| 지역 필터는 맞지만 거주 자격 조건이 다름 | 사용자가 신청했다가 거절당할 수 있음 | 자격 판정은 하지 않는다. 판단은 사용자가 원문에서 한다(서비스 원칙). 수집된 `대상자격` 원문만 그대로 보여준다 |
| 소스끼리 같은 강좌가 중복됨 | 목록 품질 저하 | 제목·기관·시작일 정규화 키로 중복을 제거한다 |

## 5. 사람이 결정해야 할 것

1. 고용24 키 발급용 **사업자 명의**를 언제 준비할지
2. **이벤터스·온오프믹스** 수집 여부 (미결, 추후 결정)
3. MVP 대상 지역을 **전국**으로 할지, **서울·경기 먼저**로 할지 (N잡형 강좌는 수도권에 몰려 있다)

## 6. 남은 미확인 항목 (원문 문서에 표시)

- 표준데이터 API의 정확한 파라미터(활용신청 후 확인 가능), 라이선스 유형
- 고용24 API의 일일 호출 한도, data.go.kr 키로 고용24 API를 호출할 수 있는지
- KDC 자부담을 수료 후 돌려받는지
- 디지털배움터 개별 강좌명 (목록을 직접 받아보지 못함)
- 네이버 파트너스퀘어 (조사 도구로 접속 실패)
