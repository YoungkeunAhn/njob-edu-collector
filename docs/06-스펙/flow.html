1. 시스템 구성

앱은 DB에 직접 접근하지 않습니다. Worker 하나가 조회 API(fetch)와 수집(scheduled)을 모두 맡습니다.

2. 사용자 플로우

3번 이내 선택으로 목록 도달(SC-001). 광고는 목록·상세의 배너뿐이라 흐름을 막지 않습니다.

flowchart TD
  A(["앱 진입 (광고 없음)"]) --> B["지역 선택
시도 → 시군구"]
  B --> C["분야 선택
대분류 → 소분류"]
  C --> D["유형 선택
원데이 클래스 / 교육훈련"]
  D --> E["[강의 찾기]"]
  E --> H["목록
지역 강좌 + 온라인(전국)
접수 마감일 순
5번째 카드 뒤 배너 1개 (실패 시 숨김)"]
  H --> I{"결과 있음?"}
  I -- "없음" --> J["조건에 맞는 강좌가 없어요
[조건 바꾸기]"] --> B
  I -- "있음" --> K["강좌 카드
제목 · 기관 · 지역 · 기간 · 가격 · 유형 · 마감일"]
  K --> L["상세 (앱 안)

안내: 신청 조건은 원문에서 확인
본문 아래 배너 1개 (원문 보기 버튼과 떨어뜨림)"]
  L --> M["보조 버튼 [원문 보기]"]
  M --> N(["openURL → 원문 사이트
판단 · 신청은 사용자"])
  L -- "뒤로" --> H

3. 조회 시퀀스

목록 조회와 배너 로드는 따로 진행됩니다. 조회는 캐시를 먼저 보고, 없을 때만 Supabase를 읽습니다.

sequenceDiagram
  autonumber
  actor U as 사용자
  participant A as 미니앱
  participant AD as 배너 광고
  participant W as Worker (fetch)
  participant C as Cache API
  participant DB as Supabase

  U->>A: 필터 선택 후 [강의 찾기]
  A->>W: GET /courses?sido&cat&type
  W->>W: Rate Limit · 파라미터 검증
  W->>C: 캐시 조회
  alt 캐시 적중
    C-->>W: 응답
  else 미적중
    W->>DB: select (마감 전 · 분류됨 · 지역 or 온라인)
    DB-->>W: 행
    W->>C: 1시간 저장
  end
  W-->>A: 목록 JSON (화면 컬럼만)
  A-->>U: 목록 표시
  par 5번째 카드 뒤 1개
    A->>AD: 배너 로드
    alt 성공
      AD-->>A: 배너 표시
    else 실패
      AD-->>A: 오류 → 자리 숨김
    end
  end
  U->>A: 강좌 선택 → [원문 보기]
  A->>U: openURL(원문)

4. 수집 배치

갱신 주기에 맞춰 매일 3그룹 + 주 1회 1그룹으로 나눕니다. 모집 중인 것만 받고, 마감된 강좌는 지웁니다. 소스 하나가 실패해도 다음 소스로 넘어갑니다.

flowchart TD
  T1(["매일 03:00 A. 공식 API
고용24 · 서울예약 · 대구 · K-Startup"]) --> L
  T2(["매일 03:20 B. 정적 HTML
서울평생학습 · SeSAC · 데브이벤트 · 링커리어"]) --> L
  T3(["매일 03:40 C. 헤드리스
AI디지털배움터"]) --> L
  T5(["매주 월 04:30 D. 주간
평생학습 표준데이터 · K-MOOC · 온통청년"]) --> L
  L["그룹 내 소스 순차 실행"] --> F["fetch (모집 중인 것만)
API · HTML · 헤드리스"]
  F --> OK{"성공?"}
  OK -- "아니오" --> E["collect_run에 오류 기록"] --> NX
  OK -- "예" --> N["normalize
공통 스키마 · raw 보관"]
  N --> TY["course_type 판정
국비훈련=교육훈련 · 시작=종료일이면 원데이
날짜 없으면 제목 키워드"]
  TY --> RG["지역 매핑
주소 → 법정동 시군구 코드"]
  RG --> UP["upsert (source, source_id)
이번 수집에 없는 행 삭제
(성공 · 건수 50% 이상일 때만)"]
  UP --> RUN["collect_run 기록
건수 · 성공"] --> NX{"다음 소스?"}
  NX -- "있음" --> F
  NX -- "없음" --> END1(["그룹 종료"])

  T4(["매일 04:00 후처리"]) --> P1["마감 정리
접수 마감일(없으면 교육 시작일) 지난 행 삭제"]
  P1 --> P2["카테고리 분류
키워드 룰"]
  P2 --> P3["키워드 미매칭 → 노출 안 함"]
  P3 --> P4["중복 표시
제목 정규화 + 기관 + 시작일"]
  P4 --> P5{"실패 또는 전일 대비 50% 이상 감소?"}
  P5 -- "예" --> AL["텔레그램 알림
Bot API sendMessage"]
  P5 -- "아니오" --> END2(["완료"])
  AL --> END2

5. 데이터 모델
