지금까지 논의해 확정한 설계를 GitHub Spec Kit 형식(`spec.md`, `plan.md`)으로 정리한 폴더다. **구현은 이 폴더를 기준으로 한다.**

## 문서 인덱스

| 문서 | 내용 |
|---|---|
| [spec.md](spec.md) | 무엇을, 왜: 서비스 원칙, 사용자 스토리 3개(조회·상세·수집), 엣지 케이스, 기능 요구사항 FR-001~014, 핵심 엔티티, 성공 기준 |

| [flow.html](flow.html) | 다이어그램 5개: 시스템 구성, 사용자 플로우, 조회 시퀀스, 수집 배치, 데이터 모델 (브라우저로 열기) |

## 확정 요약
- 앱: 앱인토스 WebView (Vite + React)
- 조회 API + 수집: Cloudflare Worker 1개 (`fetch` + `scheduled`), Workers Paid $5/월
- DB: Supabase Free (서울). 앱은 DB에 직접 접근하지 않음
- 광고: 배너, 화면당 1개. 목록은 5번째 카드 뒤, 상세는 본문 아래. "나에게 맞는 세미나 찾기" 버튼을 누르면 목록이 바로 뜬다
- 원문 링크: 상세 화면 보조 버튼 (`openURL`)
