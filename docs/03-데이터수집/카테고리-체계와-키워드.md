# 카테고리 체계와 분류 키워드 사전 (초안)

- 작성일: 2026-10-11 / 담당: E
- 관점: "이걸 배우면 부업·N잡으로 돈을 벌거나 본업 시간을 줄일 수 있나?" 사용자가 고르는 단위는 **대분류 6개**. 소분류는 필터·배지·분류 정확도용.
- 키워드는 초안이다. 실제 수집 데이터 제목을 보고 월 1회 고친다.

## 1. 카테고리 트리

| 대분류 (코드) | 소분류 (코드) | N잡 연결 예 |
|---|---|---|
| **AI 영상·이미지** (`video`) | AI 영상 제작 (`video_gen`) | 숏폼·유튜브 채널, 영상 외주 |
| | AI 이미지·디자인 (`image_gen`) | 썸네일·상세페이지 외주, 굿즈 |
| | AI 음악·음성 (`audio_gen`) | 내레이션, 배경음악, 오디오북 |
| **AI 코딩·바이브코딩** (`coding`) | 바이브코딩·노코드 앱 (`vibe`) | 앱·웹 MVP 외주, 1인 SaaS |
| | AI 활용 프로그래밍 (`ai_dev`) | 개발 부업, 프리랜서 |
| | 데이터 분석 (`data`) | 데이터 리포트 외주 |
| **콘텐츠·블로그 수익화** (`content`) | 블로그·글쓰기 (`blog`) | 애드센스, 체험단, 원고 외주 |
| | 유튜브·SNS 운영 (`sns`) | 채널 수익, 인플루언서 |
| | 전자책·온라인 강의 (`ebook`) | 전자책 판매, 강의 판매 |
| **AI 커머스·마케팅** (`commerce`) | 온라인 쇼핑몰·스마트스토어 (`store`) | 1인 셀러 |
| | AI 마케팅·광고 (`marketing`) | 마케팅 대행 |
| **업무 자동화** (`automation`) | 자동화 툴 (n8n·Make·Zapier) (`nocode_auto`) | 자동화 구축 외주 |
| | 사무 자동화 (엑셀·RPA·스프레드시트) (`office_auto`) | 본업 효율, 사무 대행 |
| | AI 에이전트·챗봇 만들기 (`agent`) | 챗봇 구축 외주 |
| **생성형 AI 기초·활용** (`genai`) | 생성형 AI 입문 (`genai_basic`) | 모든 N잡의 출발점 |
| | 프롬프트 엔지니어링 (`prompt`) | 프롬프트 판매, 업무 활용 |
| | 직무별 AI 활용 (`genai_work`) | 소상공인·사무직·교사 등 직무 적용 |
| | AI 자격증 (`genai_cert`) | 강사·컨설팅 경력 |

- 디지털 기초(스마트폰·키오스크 사용법)는 N잡 관점에서 빼고, 필요하면 나중에 `digital_basic`으로 추가.
- 한 강좌에 소분류 1개만 붙인다(MVP). 다중 태그는 필요해지면.

## 2. 분류 키워드 사전

매칭 규칙: 제목+설명 앞 300자를 소문자·공백 제거로 정규화 후 부분 문자열 매칭. 제목 매칭 가중치 2, 설명 1. 영문은 소문자로.

### AI 관련성 게이트 (하나라도 있어야 분류 진행)
`ai`, `인공지능`, `생성형`, `챗gpt`, `chatgpt`, `gpt`, `claude`, `클로드`, `gemini`, `제미나이`, `제미니`, `코파일럿`, `copilot`, `llm`, `미드저니`, `midjourney`, `노코드`, `자동화`, `바이브코딩`, `프롬프트`, `에이전트`
- 예외: `블로그`, `스마트스토어`, `유튜브`, `엑셀` 강좌는 AI 단어가 없어도 N잡 관련성이 높으므로 게이트 통과(설정값으로 on/off).
- `ai` 2글자 단독은 오탐이 많다(`maintenance`, 사람 이름 등). 영문은 단어 경계(`\bai\b`)로, 한글 문맥에선 `ai활용`, `ai를`, `ai로`, `ai 영상` 등과 함께 쓰인 경우만.

## 3. 충돌 규칙

- 여러 소분류가 같은 점수면: 더 구체적인 쪽 우선. 우선순위 `vibe` > `video_gen` > `image_gen` > `audio_gen` > `nocode_auto` > `agent` > `blog` > `sns` > `ebook` > `store` > `marketing` > `office_auto` > `data` > `ai_dev` > `prompt` > `genai_work` > `genai_cert` > `genai_basic`.
  - 예: "챗GPT로 블로그 수익화" → `blog` (챗gpt는 `genai_basic`이지만 우선순위 낮음)
  - 예: "생성형AI 기초와 업무활용" → `genai_work`
  - 구현 규칙(2026-10-11 확정): 점수만으로는 위 예시에서 `genai_basic`(4점)이 `genai_work`(2점)를 이긴다. 그래서 **다른 소분류가 제목에 걸리면 `genai_basic`은 후보에서 뺀다.** 다른 소분류가 설명에만 걸렸으면 점수로 비교한다. 구현: `worker/src/core/classify.ts`
- 그래도 애매하면(게이트만 통과, 소분류 0점 등) 노출하지 않는다(plan D13, LLM 분류는 쓰지 않음).

## 4. LLM 분류 프롬프트 골격

```
다음 강좌를 아래 코드 중 하나로 분류하라. AI·N잡과 무관하면 none.
코드: video_gen, image_gen, audio_gen, vibe, ai_dev, data, blog, sns, ebook,
      store, marketing, nocode_auto, office_auto, agent, genai_basic, prompt,
      genai_work, genai_cert, none
강좌명: {title}
기관: {provider}
설명(앞 300자): {desc}
JSON으로만 답: {"code": "...", "confidence": 0~1}
```
- confidence < 0.6이면 `category_by='llm'`이어도 노출하지 않고 수동 검토 큐(관리 화면 필터)로.
