## 핵심 결론

1. **API로 바로 받을 수 있는 소스 3개로 MVP를 시작한다**: 고용24 국민내일배움카드 훈련과정(K-디지털 포함, 실시간), 전국평생학습강좌표준데이터(전국 평생학습관, 분기), 서울 공공서비스예약 교육(수시, 실호출 확인). 모두 상업 이용 가능(제한 없음 또는 공공누리 1유형). 표준데이터만 라이선스 표기를 확인하지 못했다.
2. **고용24 API 키는 "기업회원 전용", 담당자 심사 후 발급된다.** 사업자 명의 준비가 선행 과제다. 반면 data.go.kr·서울·경기 API는 개인도 바로(자동승인) 받는다.
3. **크롤링은 "공개 목록의 사실 정보 + 원문 링크"로 한정한다.** 여기어때 사건은 형사 무죄(대법원 2021도1533)였지만 민사에서 10억 원 배상(서울고법 2021나2034740)이 났다. 경쟁 플랫폼 DB 복제, 로그인·차단 우회, 설명문·이미지 복제는 하지 않는다.
4. **파이프라인은 함수 2개짜리 어댑터 + Postgres 테이블 1개면 된다.** `unique(source, source_id)` upsert, 3일 연속 미노출 시 마감, 지역은 법정동코드 앞 5자리(시군구). 고용24 지역코드는 법정동과 달라 매핑표가 필요하다.
5. **분류는 키워드 룰 먼저, 애매한 것만 LLM**으로 보낸다. 대부분 소스에 AI와 무관한 강좌가 섞여 있어 "AI 관련성 게이트"가 노출 품질을 좌우한다.
