## 판정 기준

| 판정 | 뜻 |
|---|---|
| ✅ 가능 | 공식 API가 있거나, robots.txt가 허용하고 정적 HTML로 파싱된다 |
| 🟡 조건부 | 기술적으로는 된다. 다만 인증키·헤드리스 브라우저가 필요하거나 약관 조항이 걸린다 |
| ⛔ 막힘 | robots.txt가 수집 경로를 Disallow한다. 기술적으로 수집은 가능하다 |
| ✋ 수동 | 통합 목록이 없거나 공고가 흩어져 있어 사람이 등록해야 한다 |
| ❓ 미확인 | 구조나 robots 여부를 확인하지 못했다 |
