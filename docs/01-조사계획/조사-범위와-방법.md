# 조사 범위와 방법

- 작성일: 2026-10-11

## 1. 목적

N잡러 교육 매칭 서비스(토스 인앱 배포 예정)에 넣을 **AI 활용 교육 소스**를 찾는다.
AI 영상 제작, AI 코딩/바이브코딩, 블로그·콘텐츠 수익화, 업무 자동화(n8n·Make·RPA), 생성형 AI 활용 같은 강의가 대상이다.

서비스에서 말하는 매칭은 단순하다. 사용자가 **지역 + 분야(카테고리)**를 고르면 들을 수 있는 강의 목록을 보여준다.
강의 데이터는 매일 정해진 시간에 크롤링하거나 API로 받아 DB에 쌓는다.

토스 인앱 자체는 조사 범위에서 뺐다.

## 2. 조사 질문

1. AI 관련 교육은 **어디에** 있나? (공공·국비·평생교육·민간·커뮤니티)
2. 각 소스의 **비용 구조**는? (무료 / 내일배움카드 / 자부담 / 유료)
3. **지역성**이 있나? (특정 시도·시군구 거주자 한정, 오프라인 장소)
4. 데이터를 **어떻게 가져올 수 있나**? (공식 Open API / 목록 페이지 크롤링 / RSS / 수동)
5. 크롤링할 때 **법적·기술적 제약**은? (robots.txt, 이용약관, 로그인 필요, JS 렌더링)

## 4. 소스별 기록 템플릿

각 소스 문서는 아래 항목을 채운다. 확인하지 못한 항목은 `미확인`으로 적는다.

```markdown
### <소스명>
- URL:
- 운영 주체:
- 대상/자격: (거주지 제한, 연령, 재직/구직 여부)
- 비용: 무료 / 내일배움카드 / 자부담 n% / 유료
- 지역: 전국 온라인 / 특정 지역 오프라인
- AI 관련 강의 예시: (실제 강의명 2~3개)
- 갱신 주기: (상시 / 분기 모집 등)
- 데이터 수집: Open API / 목록 크롤링 / RSS / 수동 — 근거
- 제약: robots.txt, 로그인, JS 렌더링, 약관
- 서비스 우선순위: 상/중/하 — 이유
- 확인일 / 출처:
```
