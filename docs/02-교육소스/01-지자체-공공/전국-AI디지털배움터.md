# 전국 AI디지털배움터 (과기정통부·NIA)

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

## 핵심 요약

- 2026년에 "디지털배움터"가 **"AI디지털배움터"**로 개편됐다. 기존 거점 37곳에 신규 32곳을 더해 전국 69개 거점으로 늘었다(과기정통부, 2025-12-24 발표).
- 서울·경기·인천·울산·대구·광주·부산 같은 시도 사업도 **모두 같은 전국 누리집(디지털배움터.kr)에 강좌를 올리고 신청을 받는다**. 각 시도 보도자료가 "디지털배움터 누리집 또는 콜센터 1800-0096"을 신청 경로로 안내한다.
- 그래서 이 누리집 하나만 수집해도 **전국 지자체 공공 AI 기초교육 대부분**이 들어온다. 영역 A에서 수집 1순위다.
- 다만 강좌 목록은 토큰을 붙인 내부 AJAX로 불러오기 때문에 단순 HTTP 크롤링이 막혀 있다. 아래 "데이터 수집" 항목을 본다.

### AI디지털배움터 (전국 누리집)
- URL: https://www.디지털배움터.kr (punycode `https://www.xn--2z1bw8k1pjz5ccumkb.kr`) → `/entry.do` → 교육 신청 목록 `/edc/crse/req/list.do`
- 운영 주체: 과학기술정보통신부, 한국지능정보사회진흥원(NIA, 대구 동구 첨단로 53). 시도·시군구가 거점센터와 교육장을 운영한다.
- 대상/자격: 전 국민. 2026년부터 고령층·장애인 중심에서 중장년, 소상공인, 일반 국민까지로 넓혔다. 시도 사업 공고는 대개 "○○시민 누구나"로 표현한다. 거주지를 엄격히 확인하는지는 미확인.
- 비용: 무료(시도 공고에 "전액 무료"로 표기. 서울·인천·울산 확인)
- 지역: 전국 오프라인(거점센터, 주민센터, 복지관, 우체국 등)과 일부 온라인. 검색 필터는 시도 → 시군구 → 읍면동이다(`/api/edc/place/addr.do`).
- AI 관련 강좌 예시:
  - 서울: 과정 구분 "AI 기초 / AI 생활 / AI 심화 / AI 특별", 대상별 "AI 올인원 패키지"(소상공인 AI 마케팅·매출 분석, 직장인 업무 자동화·데이터 활용)
  - 마포구: 챗GPT 활용, AI 사진 복원, AI 음악·애니메이션 제작
  - 경기: 생성형 AI 활용(문서 작성·이미지 생성 실습), AI 기반 SNS 마케팅, 온라인 창업·홍보 콘텐츠 제작
  - 실제 개별 강좌명은 목록 API를 호출하지 못해 직접 확인하지 못했다(미확인).
- 갱신 주기: 상시. 2026년 사업은 3~5월에 시작해 12월까지 운영하고, 회차별 모집은 지역마다 다르다.
- 데이터 수집: **목록 크롤링(헤드리스 브라우저 필요)**. 근거:
  - 목록 HTML은 빈 껍데기이고("총 0 건"), `/js/plugin/edc/crse/edc_req_list.js`가 `POST /api/edc/req/list.do`로 JSON(`RK_RESULT`, `RK_TOTAL`)을 받아 화면을 그린다.
  - 요청 파라미터: `supr_cd=1`, `edu_type=E`, `grp_se_yn=N`, `sch_area_cd`(시도), `sch_signgu_cd`, `sch_edc_mthd_se_cd`(교육방식), `sch_edc_bgn_dt`/`sch_edc_end_dt`, `sch_edc_crse_se_cd`(과정구분), `sch_edc_plan_nm`(교육명), `sch_std_capa_cd[]`(역량), `sch_oper_sttus_se_cd`(교육일정상태), `sch_edc_trgter_ty_cd`(대상자유형), `page_no`, `page_size`
  - 응답 필드(JS 기준): `edc_place_nm`, `edc_mthd_se_cd`, `real_edc_plc`, `edc_plc_adres`, `oper_sttus_se_cd`, `favr_cnt` 등. 상세 페이지는 `/edc/crse/req/dtl_step1.do?...`
  - 요청 헤더에 `x-nia-header`, `x-nia-token`(쿠키 `X-NIA-FT-HEADER`/`X-NIA-FT-TOKEN`)이 필요하다. curl로 세션 쿠키만 붙여 직접 호출하니 "허용되지 않는 요청" 오류가 났다. 토큰을 발급하는 위치는 찾지 못했다(미확인).
  - 공식 Open API는 확인하지 못했다. 공공데이터포털에는 "대구광역시_디지털배움터 현황"(배움터명·주소·유형, 강좌 정보 없음) 같은 시도 단위 **장소 데이터**만 있다.
- 제약: robots.txt 없음(404). 목록 조회는 로그인 없이 되고 신청은 로그인이 필요하다. JS 렌더링과 토큰 헤더 때문에 Playwright 같은 브라우저 자동화가 필요하다. 이용약관 `/bt/membership.do`는 크롤링 관련 조항을 확인하지 못했다(미확인).
- 서비스 우선순위: **상**. 무료이고 전국을 덮으며 지역 필터(시도·시군구·읍면동)가 서비스의 "지역 + 분야" 매칭 구조와 그대로 맞는다. 다만 기초·생활형 강좌가 많아 "N잡러 수익화" 성격은 약하다. 심화·특별 과정과 소상공인 과정 위주로 걸러야 한다.
