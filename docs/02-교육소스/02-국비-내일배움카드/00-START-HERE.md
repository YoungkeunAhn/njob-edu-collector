# 02-국비-내일배움카드 — 진입점

- 작성일: 2026-10-11 (조사 영역 B)

국비지원·국민내일배움카드 교육을 조사했다. 핵심 결론은 하나다. **KDT·KDC·산대특·국기·일반 내배카 과정이 전부 고용24 과정 DB 하나에 들어 있고, 고용24 Open API(`callOpenApiSvcInfo310L01`)로 지역(시도·시군구)·NCS·훈련유형·시작일 필터를 걸어 받을 수 있다.**
걸리는 점은 인증키다. 고용24 **기업회원 전용**이고 심사 후 발급되므로 사업자등록부터 해야 한다. 키를 받기 전에는 고용24 공개 검색 화면(SSR)을 크롤링해 임시로 쓸 수 있다.
2026년부터 KDT·국기·산대특에 자부담 구간제(10%~최대 60만원)가 생겼다. AI 캠퍼스는 면제다. "국비=무료"로 표기하면 안 된다.

## 영역 E(데이터수집)에 넘길 것

- 고용24 OPEN-API 기업회원 가입과 인증키 신청을 **가장 먼저** 진행해야 한다(심사 기간이 필요하다).
- 이 API에는 AI 카테고리가 없다. 과정명 키워드와 NCS로 우리 카테고리를 직접 붙여야 한다.
- 원격(M1005)·KDC 과정은 지역이 없으니 "전국 온라인"으로 처리한다.
- 과정명이 같은 중복(여러 원격평생교육원이 같은 콘텐츠를 등록)과 매일 개강하는 회차를 묶어야 한다.
