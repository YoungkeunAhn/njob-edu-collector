# 행사·이벤트 플랫폼

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

주최자가 직접 행사를 올리는 플랫폼이다. 민간 학원, 협회, 지자체 위탁기관, 도서관, 기업 세미나가 한곳에 섞여 있어 **이 영역에서 수집 효율이 가장 높다.** 지역·비용·온오프라인·카테고리가 구조화 필드로 있는 곳이 많다.

요약: **이벤터스가 1순위**(구조화 JSON 응답, 지역·무료 필드, robots 허용). 데브이벤트는 GitHub README로 받을 수 있지만 개발자 행사 위주. 온오프믹스는 데이터는 좋은데 robots.txt가 일반 크롤러를 전면 차단한다.

---

### 이벤터스 (event-us.kr)
- URL: https://event-us.kr/ (검색: `https://event-us.kr/search?query=AI&order=score&date=모든날&page=1`)
- 운영 주체: 주식회사 이벤터스
- 대상/자격: 행사마다 다름(재직자 한정, 소상공인 한정, 지역 주민 한정 등이 제목·본문에 표기)
- 비용: 무료 행사 다수. 유료는 1,000원(노쇼 방지 보증금)부터 수십만 원까지
- 지역: 전국. 오프라인 행사는 `area_detail`(예: "충남 천안시 동남구")과 좌표 제공, 온라인·하이브리드 구분
- AI 관련 강의 예시 (2026-10-11 검색 결과):
  - [천안/무료교육] 포스터부터 숏폼·CM송까지 AI로 우리 상품 홍보 콘텐츠 직접 만들기 (2026-10-21, 충남 천안, 무료, 채널 `ailounge`)
  - 한국디지털융합교육협회 구글 AI 제미나이 무료특강 — 서산(10-15)·김포(11-06)·광주(11-10)·마포(11-12) 순회, 무료
  - [전액무료] 대구 소상공인 맞춤형 AI 무료 교육 2회차 (2026-10-26, 대구 북구)
  - [재직자 무료] 4시간 만에 일잘러 되기 X AI 웹·업무 자동화 바이브코딩 A to Z (2026-10-16, 서울 성동구)
  - [국립중앙도서관/무료교육] AI 아트 클래스: AI로 나도 영상 제작자(기본) (2026-11-04, 서울 서초구)
  - 와구와구 | 만들고 싶던 영상, AI로 직접 만들기 (2026-10-19, 서울 서초구, 유료 90,000원)
  - "바이브코딩" 검색 결과만 254건
- 갱신 주기: 상시(주최자 등록). 검색 인덱스 `collected_at` 값이 2026-10-11T04:00Z로 보아 인덱스도 수시 갱신
- 데이터 수집: **비공식 내부 JSON API** — 검색 페이지가 `POST https://api.event-us.kr/api/v1/engine/search`를 호출한다(페이지 JS의 `engineApiBase`). 직접 호출해 확인함. 요청 `{"query":"AI 교육","page":{"current":1,"size":15}}` → 응답 `results[]`에 `id, subdomain, title, start_date, close_date, register_start_date, register_due_date, area, area_detail, full_address, location, place, event_system_type(offline/online/hybrid), payway, min_money, category, category2, tags, state, cover_image_url, description` 등. 상세 URL은 `https://event-us.kr/{subdomain}/event/{id}` (200 확인). 응답은 `total_results` 10,000에서 잘리므로 키워드별로 나눠 호출해야 함. 공개 Open API는 확인 안 됨
- 제약:
  - robots.txt: `User-agent:* Allow:/`. `/rss/event`, `/biz/*`, `/user/applicant/*` 등만 차단. `api.event-us.kr`의 robots는 미확인
  - 이용약관 제13조 1항 2호: "서비스를 이용하여 얻은 정보를 회사의 사전 승낙 없이 영리 또는 비영리의 목적으로 복제, 출판, 방송 등에 사용하거나 제3자에게 제공하는 행위" 금지. 크롤링 명시 금지 조항은 없음. **상용 수집 여부는 미결**
  - 검색 결과에 과거 행사(2024년 등)가 섞여 나오므로 `start_date`/`register_due_date`로 걸러야 함
  - 국비 부트캠프 홍보 행사도 많아 B영역(국비)과 중복될 수 있음
- 서비스 우선순위: **상** — 지역·무료·온오프라인 필드가 구조화돼 있어 "지역 + 분야" 매칭에 바로 맞고, 동네 무료 AI 특강이 가장 많이 모이는 곳
- 확인일 / 출처: 2026-10-11 / https://event-us.kr/robots.txt , https://event-us.kr/legal/service , 검색 API 직접 호출

- 제약: **robots.txt가 검색엔진·미리보기·AI 조회 봇(Googlebot, Yeti, Claude-User 등)만 허용하고 `User-agent: *`는 `Disallow: /`.** 자체 수집기는 차단 대상. 약관 제14조 8항 7호(서비스 외 목적 복제·제3자 제공 금지), 제19조 2항(취득 정보의 가공·판매 등 상업적 사용 금지)
- 서비스 우선순위: 중(데이터 가치) / 수집 여부 **미결**
- 확인일 / 출처: 2026-10-11 / https://www.onoffmix.com/robots.txt , https://www.onoffmix.com/legal/agreement
