# 클래스·모임 플랫폼

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

취미 클래스, 원데이 모임, 재능 거래 플랫폼이다. AI 관련 상품은 있지만 **대부분 유료이고 목록이 JS로 렌더링**돼 수집이 까다롭다. "무료·지역 AI 교육"이라는 서비스 핵심과는 거리가 있다. 우선순위는 전반적으로 하. 유료 강의까지 넣기로 하면 그때 수집 방식을 다시 본다.

---

### 소모임
- URL: https://www.somoim.co.kr
- 운영 주체: (주)프렌즈큐브
- 대상/자격: 회원(앱 가입)
- 비용: 모임별(대개 회비·참가비 소액, 미확인)
- 지역: 오프라인, 시·구 단위(`/groups/search?loc1n={시도}&loc2n={구}`)
- AI 관련 예시: "AI로 뭐까지 해봤어요?"(업종/직무, 영등포구), "코워크루 | AI 코워킹 모임"(강서구), "it&ai 스터디"(자기계발, 마포구)
- 갱신 주기: 상시
- 데이터 수집: 웹 목록 존재 — 모임 상세 `/{UUID}`, 정모 `/{UUID}?e_d=YYYYMMDD&e_t=HHMM`, 카테고리 `/{카테고리명}`. 18개 카테고리에 AI 전용 분류는 없고 업종/직무·자기계발에 섞여 있음
- 제약: robots.txt `User-agent: * Allow: /`, sitemap 있음. 약관 미확인. 강의가 아니라 친목·스터디 모임이라 "교육"으로 분류하기 애매함
- 서비스 우선순위: 하 — 강의 정보 아님. "AI 스터디 모임" 탭을 따로 만들 때만 검토
- 확인일 / 출처: 2026-10-11 / https://www.somoim.co.kr , https://www.somoim.co.kr/robots.txt

### 문토 (munto.kr)
- URL: https://www.munto.kr
- 운영 주체: 미확인
- 대상/자격: 회원
- 비용: 유료 소셜링·클럽(금액 미확인)
- 지역: 오프라인(서울 중심으로 알려짐, 미확인)
- AI 관련 예시: 미확인(페이지가 JS 렌더링이라 확인 못 함)
- 데이터 수집: 어려움
- 제약: **robots.txt `User-agent: * Disallow: /`**, 검색엔진 봇에만 `/moim*` 허용
- 서비스 우선순위: 하(제외)
- 확인일 / 출처: 2026-10-11 / https://www.munto.kr/robots.txt

### 프립 (frip.co.kr)
- URL: https://www.frip.co.kr
- 운영 주체: 미확인
- 비용: 유료 액티비티·클래스

- 확인일 / 출처: 2026-10-11 / https://www.frip.co.kr/robots.txt

### 탈잉 (taling.me)
- URL: https://taling.me
- 운영 주체: 미확인
- 비용: 유료(원데이·VOD). 평생교육 사이트(lifelong-taling.kr) 별도 링크 있음 — C영역 확인 대상일 수 있음
- 지역: 온라인 + 오프라인(검색 필터에 클래스 유형·지역·일정)
- AI 관련 예시: 미확인(검색 결과가 JS로 로드돼 확인 못 함)
- 데이터 수집: 목록 크롤링 어려움(CSR). sitemap 있음 — sitemap으로 상세 URL을 받아 파싱하는 방법은 가능성 있음(미검증)
- 제약: robots.txt는 결제·마이페이지 경로만 차단
- 서비스 우선순위: 하
- 확인일 / 출처: 2026-10-11 / https://taling.me/search?query=AI , https://taling.me/robots.txt

### 클래스101 (class101.net)
- URL: https://class101.net
- 비용: 유료 구독·VOD
- 지역: 전국 온라인(지역성 없음)
- AI 관련 예시: 미확인
- 데이터 수집: robots.txt가 `/products`를 Disallow하면서 `/products/`는 Allow하는 혼재 상태. 상품 페이지 수집 허용 범위가 모호함
- 서비스 우선순위: 하 — 유료 온라인 VOD는 지역 매칭과 무관
- 확인일 / 출처: 2026-10-11 / https://class101.net/robots.txt

### 인프런 (inflearn.com)
- URL: https://www.inflearn.com (AI 태그 큐레이션 https://www.inflearn.com/tag-curation/skill/ai)
- 비용: 유료 중심, 무료 강의 일부
- 지역: 온라인. 오프라인 밋업·컨퍼런스(인프콘 등)는 2026년 일정 미확인
- 데이터 수집: robots.txt `User-agent: *`에서 `/api` 등 차단, 강의 목록 경로는 허용. 공개 API 미확인
- 서비스 우선순위: 하 — 온라인 유료 강의라 지역 매칭과 무관. "온라인 무료" 필터가 생기면 무료 강의만 검토
- 확인일 / 출처: 2026-10-11 / https://www.inflearn.com/robots.txt
