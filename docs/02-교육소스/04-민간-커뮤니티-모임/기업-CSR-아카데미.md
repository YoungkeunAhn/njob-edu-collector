# 기업 CSR·재단 아카데미

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

대기업·재단이 사회공헌으로 운영하는 무료 AI·SW 교육이다. 공통점이 뚜렷하다.

- **1년에 1~2번 기수 모집**하는 장기 과정(6개월~1년). 상시 목록이 없다.
- 대상이 **만 29~34세 이하 미취업 청년, 특정 대학 재학생**처럼 좁다. N잡러(재직자·부업 희망자)와는 잘 맞지 않는다.
- 데이터는 공식 사이트 공지·보도자료 몇 건이라 크롤러를 만들 가치가 낮다. **수동 등록(연 몇 건) + 모집 기간 알림**이 맞다.

예외적으로 N잡러에게 쓸모 있는 것은 상시 무료 온라인 강의(부스트코스, 구글 AI 과정)와 네이버 파트너스퀘어(스마트스토어·블로그 수익화)다.
