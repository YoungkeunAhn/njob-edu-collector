## 요약

- 사용자가 예시로 든 **주변애(greenlove.kr)**는 AI 교육 사이트가 아니다. 고양(일산) 중심의 동네 커뮤니티 플랫폼(운영 (주)룰루랄라)이고, 행사 게시판에 무료 AI 특강이 월 1~2건 올라오는 정도다. 서버 렌더링이라 수집은 쉽다.
- 주변애 같은 "동네 무료 AI 특강"이 전국 단위로 가장 많이 모이는 곳은 **이벤터스(event-us.kr)**다. 검색 페이지가 쓰는 JSON 응답에 지역·좌표·무료 여부·온오프라인·카테고리가 구조화돼 있다. 이 영역의 1순위 소스다(약관 13조 때문에 상용 수집 여부는 미결).
- 온오프믹스는 데이터는 좋지만 robots.txt가 일반 크롤러를 전면 차단한다(수집 여부 미결). 페스타는 운영 중단 상태로 보인다.
- 기업 CSR 아카데미(SSAFY, KT 에이블스쿨, 카카오, LG Aimers 등)는 청년 취업용 연 1~2회 기수 모집이라 N잡러와 대상이 맞지 않는다. 수동 등록하면 충분하다.
- 클래스·모임 플랫폼(소모임, 문토, 탈잉, 클래스101 등)은 대부분 유료이고 목록이 JS로 렌더링되며, 일부는 robots.txt로 차단한다. 우선순위는 낮다.

## 다음 단계 제안

1. 이벤터스: 카테고리 키워드(AI 영상, 바이브코딩, 블로그 수익화, 업무자동화, 생성형AI)별 API 호출 → `start_date` 미래 + `area` 기준으로 걸러 표본 DB를 만든다.
2. 온오프믹스: 미결.
3. 네이버 파트너스퀘어: 브라우저로 교육 목록 구조와 로그인 필요 여부를 직접 확인한다.
4. 국비 부트캠프 홍보 행사가 이벤터스·링커리어에 많으므로, B영역(고용24) 데이터와 제목·기관명 기준 중복 제거 규칙이 필요하다(E영역 전달).
