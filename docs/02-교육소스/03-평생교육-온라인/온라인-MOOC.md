# 온라인 공공 플랫폼 (K-MOOC·온국민평생배움터·디지털새싹)

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

지역 제한 없이 누구나 듣는 국가 운영 온라인 강좌. 지역 필터에서는 "전국 온라인"으로 묶으면 된다.

---

### K-MOOC (한국형 온라인 공개강좌)

- URL: https://www.kmooc.kr
- 운영 주체: 교육부·국가평생교육진흥원 (강좌는 대학·기관이 개발)
- 대상/자격: 회원가입한 누구나 (가입은 진흥원 승낙으로 이용계약 성립)
- 비용: 무료로 알려져 있으나 이번에 열람한 강좌 상세 페이지에 수강료 표기가 없어 **미확인**. 학점은행 강좌는 별도
- 지역: 전국 온라인
- AI 관련 강좌 예시:
  - 「인공지능의 기초 이해」(고려대, 공학>컴퓨터·통신, 학습인정 6시간 50분, 운영 2026-03-10~04-28) — https://www.kmooc.kr/view/course/detail/19648
  - 「AI와의 첫 만남: 생성형 인공지능으로 보는 미래」
  - 「미래생활 속에 스민 수학, AI로 활용하기」, 마이크로러닝 「누구나 할 수 있는 AI 머신 러닝」
  - 2026년 신규 선정: 부산디지털대 '생성형 AI + 노코드 웹 제작 도구로 랜딩페이지 제작' 강좌(정확한 강좌명 미확인)
- 갱신 주기: 강좌별 수강신청기간/운영기간(학기 단위 + 상시강좌). 2026년 신규 강좌 선정 결과는 5월 19일 발표. 2026년 정책 방향이 AI·디지털 강좌 확대
- 데이터 수집: **목록 크롤링**. 공식 Open API 못 찾음(미확인)
  - 상세: `/view/course/detail/{id}` (서버 렌더링, 강좌명·기관·기간·학습시간 파싱 가능 확인)
  - 검색: `/view/search/{검색어}` → **JS 렌더링**이라 정적 fetch 시 0건. 내부 XHR 확인 필요
  - 기타 목록: `/view/course`, `/view/course/digital`(디지털+), `/view/course/aid`(재직자 AID 집중과정), `/view/course/micro`, `/view/roadmap`
  - 분야 목록은 JS 함수(`goCatePage`) 링크라 고정 URL 없음
  - 대안: 상세 페이지 id 순회(증분 수집)
- 제약: robots.txt `User-agent: * / Allow: /` (전체 허용). 이용약관 크롤링 조항 미확인
- 서비스 우선순위: **상** — 무료·전국·AI 강좌 수 많음. 다만 대학 교양 성격이 강해 "N잡/수익화" 실무 매칭은 약하다. '디지털+', '재직자 AID' 묶음이 실무형에 가깝다
- 확인일 / 출처: 2026-10-11 / https://www.kmooc.kr, https://www.kmooc.kr/robots.txt, https://dhnews.co.kr/news/view/1065598460991074

### 온국민평생배움터 (구 늘배움 국가평생학습포털)

- URL: https://www.all.go.kr (구 `www.lifelongedu.go.kr`은 인증서가 `*.all.go.kr`로 바뀌어 접속 시 all.go.kr로 넘어감)
- 운영 주체: 교육부·국가평생교육진흥원
- 대상/자격: 누구나 (개별 강좌는 운영기관 기준)
- 비용: 강좌별 상이(미확인)
- 지역: 전국. 지자체 평생학습관·대학 평생교육원·공공기관 강좌를 모아 보여주는 **관문(aggregator)** 성격(블로그 설명, 공식 확인 못함)
- AI 관련 강좌 예시: 미확인 (메인 페이지가 JS 렌더링이라 정적 fetch로 사이트명 외 내용 없음)
- 갱신 주기: 미확인
- 데이터 수집: **미확인 → 우선 표준데이터 API로 대체**. 지자체 강좌 원천이 [전국평생학습강좌표준데이터](평생학습강좌-표준데이터.md)와 겹칠 가능성이 크다. 사이트 직접 크롤링은 헤드리스 브라우저 필요
- 제약: robots.txt `User-agent: * / Allow: /`. JS 렌더링. 늘배움→온국민평생배움터 전환 시점·통합 범위는 공식 공지로 확인 못함
- 서비스 우선순위: **중** — 전국 평생학습 강좌를 다 모은 곳이지만, 같은 데이터를 표준데이터 API로 받을 수 있으면 굳이 크롤링할 이유가 적다
- 확인일 / 출처: 2026-10-11 / https://www.all.go.kr, https://www.all.go.kr/robots.txt, https://tilnote.io/pages/6a89c8bbc6e5775b11805705 (블로그)

### 디지털새싹

- URL: 통합 사이트 미확인 (한국과학창의재단 주관, 권역별 운영기관 공지)
- 운영 주체: 한국과학창의재단 주관, 대학·교육기관 컨소시엄 운영(동아대·경기대·한신대·건국대 등)
- 대상/자격: **초·중·고등학생**
- 비용: 무료
- 지역: 권역별 오프라인·캠프
- AI 관련 강좌 예시: 강남미래교육센터 '2026 디지털새싹 캠프'(초5~중1, 접수 6/16~26) 등 SW·AI 체험
- 갱신 주기: 연 단위 사업, 운영기관별 수시 모집
- 데이터 수집: 수동 — 운영기관마다 공지가 흩어져 있음
- 제약: 통합 목록 없음
- 서비스 우선순위: **하** — 성인 N잡러 대상이 아님. 제외 권장
- 확인일 / 출처: 2026-10-11 / https://www.gangnam.go.kr/board/B_000031/1075160/view.do?mid=ID01_0, https://dhnews.co.kr/news/view/1065573951208131
