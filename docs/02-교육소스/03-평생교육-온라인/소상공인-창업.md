# 소상공인 · 창업 교육 (소진공·중기부·창업진흥원)

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

AI 마케팅 영상, 상세페이지, 업무 자동화 같은 "장사에 쓰는 AI" 강좌가 많다. 블로그·콘텐츠 수익화, AI 영상제작 카테고리와 겹친다.

### 소상공인지식배움터 (소상공인시장진흥공단)

- URL: https://edu.sbiz.or.kr
- 운영 주체: 소상공인시장진흥공단(대전)
- 대상/자격: 회원가입 후 수강. 사업자등록번호 입력 시 소상공인 인증, 예비창업자는 일반회원(블로그 설명, 공식 확인은 부분). 강좌별 자격 상이, 현장교육은 '업종무관' 다수
- 비용: 현장교육 **무료(국비 100%)** 확인. 온라인 강좌 수강료 표기 없음(무료로 추정, 미확인)
- 지역: 온라인(전국) + 현장교육(지역·기수별)
- AI 관련 강좌 예시 (2026-10-11 메인):
  - 온라인 「소상공인을 위한 AI 첫걸음 - 마케팅 영상 만들기」
  - 온라인 「소상공인을 위한 AI 첫걸음 - AI 감 잡고 시작하기」
  - 온라인 「AI와 데이터 이해하기 - 데이터 분석 방법의 이해」, 「10초 만에 팔리는 이미지 제작」
  - 현장 「오늘 배워 내일 매출나는 소상공인 AI과정 with 캐시노트」(지역·기수별)
- 갱신 주기: 온라인 상시, 현장교육 수시
- 데이터 수집: **목록 크롤링**(온라인교육 > 지식배움터 교육/패키지/마이크로러닝, 현장교육 검색). Open API 미확인. 목록 URL 패턴·JS 렌더링 여부 미확인
- 제약: robots.txt·약관 미확인
- 서비스 우선순위: **상** — 무료, 전국 온라인, AI 마케팅 영상·이미지 강좌가 N잡 카테고리와 정확히 맞음
- 확인일 / 출처: 2026-10-11 / https://edu.sbiz.or.kr, https://studygov.kr/blog/1434-small-business-startup-education/

### 소상공인24 — AI+ 소상공인 상생협업교육 / 소상공인 AI 교육

- URL: https://www.sbiz24.kr (신청), 사업 소개 https://www.kpc.or.kr/kpc/biz/ai-plus.html
- 운영 주체: 중소벤처기업부·소상공인시장진흥공단, 운영기관(한국생산성본부 KPC, 카카오 등)
- 대상/자격: 소상공인(상시근로자 10명 미만, 업종에 따라 5명 미만). 대표자 명의 휴대폰 인증, 동일 사업체 1명 신청(안내 글 기준)
- 비용: **무료**(참가비 0원)
- 지역: 지역별 현장교육 (예: 카카오 소상공인 AI 교육 2025-11 판교·서울·대전 등 4개 지역)
- AI 관련 강좌 예시:
  - '2026 소상공인 AI 상생협업교육'(AI+) — KPC 지역별 일정에 'AI TOOL 기초'(생성형 AI 종류·계정 설정·프롬프트 기초, 이론+실습)
  - 카카오×중기부 '소상공인 AI 활용 교육'(4시간, 이미지·영상 생성, 홍보 콘텐츠, 반복 업무 자동화) — 2025년 회차
  - 2026 소상공인 통합교육: AI·디지털 전환이 핵심 주제, 이수 시 경영안정 바우처(블로그, 미확인)
- 갱신 주기: 연 사업, 차수별 모집
- 데이터 수집: 수동 또는 소상공인24 공고 크롤링(로그인·본인인증 필요 영역 많음, 미확인). KPC 일정 페이지 `/kpc/biz/day_detail.html` 크롤링 가능성(미확인)
- 제약: 사업자 대상이라 예비 N잡러는 대상이 아닐 수 있음
- 서비스 우선순위: **중** — 무료 AI 실습이지만 소상공인 자격 필요
- 확인일 / 출처: 2026-10-11 / https://www.kpc.or.kr/kpc/biz/ai-plus.html, https://www.kakaocorp.com/page/detail/11815, https://view.asiae.co.kr/article/2026061207570743795

### K-Startup (창업진흥원) — 사업공고 Open API

- URL: https://www.k-startup.go.kr / API https://www.data.go.kr/data/15125364/openapi.do
- 운영 주체: 창업진흥원 (중소벤처기업부 산하)
- 대상/자격: 공고별 (예비창업자, 창업 n년 이내, 연령 등)
- 비용: 공고별 (교육·멘토링 프로그램은 무료 다수, 미확인)
- 지역: 전국, 공고별 지역 필드 있음
- AI 관련 강좌 예시: 중장년 기술창업센터 교육·입주 공고, 창업기업 대상 'AI 교육' 공고 등이 섞여 올라옴. 교육만 걸러낸 목록은 없음
- 갱신 주기: 메타데이터 **실시간**(다른 문서에는 일 1회 갱신 표기 있음)
- 데이터 수집: **Open API**(REST, JSON+XML). 서비스 `kisedKstartupService01`, 기능 `getAnnouncementInformation01`(사업공고: 제목·신청기간·지역·대상·모집상태), `getBusinessInformation01`, `getContentInformation01`, `getStatisticalInformation01`(3rd-party 문서 기준, 공식 가이드 zip에서 확인 필요). 개발계정 트래픽 10,000
- 제약: K-Startup에 등록된 공고만 나옴(타 부처·지자체 공고 일부 누락). 대부분 '지원사업'이지 '강좌'가 아니라 **AI·교육 키워드 필터** 필요
- 서비스 우선순위: **중** — API가 깔끔해 붙이기 쉽지만 교육 비중이 낮다. 'AI 창업' 카테고리 보강용
- 확인일 / 출처: 2026-10-11 / https://www.data.go.kr/data/15125364/openapi.do, https://raw.githubusercontent.com/NomaDamas/k-skill/main/docs/features/kstartup-search.md
