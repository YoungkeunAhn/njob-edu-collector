# 평생학습강좌 공공데이터 (표준데이터·지자체 API)

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

평생교육 쪽에서 가장 먼저 붙일 수집 경로다. 전국 지자체와 교육청이 같은 스키마로 올리는 **전국평생학습강좌표준데이터**가 있다. 지역 평생학습관·주민센터 강좌를 개별 사이트마다 크롤링하지 않고 한 번에 받을 수 있다.

---

### 전국평생학습강좌표준데이터

- URL: https://www.data.go.kr/data/15013110/standard.do
- 운영 주체: 제공 지방자치단체·교육청 / 소관 교육부 / 공공데이터포털 병합 제공
- 대상/자격: 강좌별로 다름 (`교육대상구분` 필드: 성인·시니어·청소년·어린이·기타 값 확인)
- 비용: 강좌별 `수강료` 필드 (무료 강좌 다수로 추정, 미확인)
- 지역: 전국. `교육장도로명주소`·`운영기관명`으로 시도/시군구 매핑 가능
- AI 관련 강좌 예시: 데이터 원본에서 직접 확인 못함(미확인). 같은 스키마를 쓰는 지자체 강좌 예시로 성동구 평생학습관 'AI 시대, 든든한 내 업무 비서 만들기(챗봇)'(2026년 3분기, 무료·재료비 별도)가 있다
- 갱신 주기: 메타데이터상 **분기**. 개별 기관 등록분은 **매월 초 병합**해 전국 단위로 제공(병합 시점 차이로 지연 가능). 페이지 수정일 2026-09-03. 제공기관 목록 348건 표시(레코드 수 아님)
- 데이터 수집: **Open API + 파일 다운로드**. 그리드 다운로드는 5만 행 제한이 있어 전체는 API 사용 권장(페이지 안내). 회원가입·활용신청 후 서비스키 발급
  - 엔드포인트/파라미터: 미확인. 표준데이터 API는 보통 `api.data.go.kr/openapi/tn_pubr_public_...` 형태지만 이 데이터셋의 정확한 경로는 확인 못했다. 활용신청 후 명세 확인 필요
- 제약: 공공데이터 이용허락(출처표시) 수준으로 추정, 미확인. 기관마다 입력 품질 차이(날짜 형식이 VARCHAR/DATE 혼재 사례 있음)
- 서비스 우선순위: **상** — 전국 지역 평생학습관·주민센터 강좌를 한 스키마로 받는 유일한 경로. 지역 필터와 바로 맞는다. 단, 갱신이 월~분기 단위라 "모집 중" 실시간성은 약하다
- 확인일 / 출처: 2026-10-11 / https://www.data.go.kr/data/15013110/standard.do

#### 필드(표준 항목 24개)

| 필드 | 서비스 활용 |
|---|---|
| 강좌명, 강좌내용 | AI 키워드 분류(카테고리 매칭) |
| 강사명 | 표시용 |
| 교육시작일자, 교육종료일자, 교육시작시각, 교육종료시각, 운영요일 | 일정 표시·종료 강좌 제외 |
| 교육대상구분 | 성인/시니어/청소년/어린이/기타 → 연령 필터 |
| 교육방법구분 | 온라인/오프라인(설명상 혼합·우편통신·모바일도 있음) |
| 교육장소, 교육장도로명주소 | 지역(시도·시군구) 필터 |
| 강좌정원수, 수강료 | 비용 필터 |
| 운영기관명, 운영기관전화번호, 홈페이지주소 | 신청 링크(딥링크 없음, 기관 홈 수준일 가능성) |
| 접수시작일자, 접수종료일자, 접수방법구분, 선정방법구분 | "모집 중" 판정 |
| 직업능력개발훈련비 지원강좌여부, 학점은행제평가(학점) 인정여부, 평생학습계좌제평가 인정여부 | 부가 배지 |

코드값 공식 목록은 「공공데이터 제공 표준」 문서(공공데이터포털 > 정보공유 > 자료실)에 있다고 안내됨. 미확인.

### 대구광역시_평생학습포털_강좌조회서비스 (Open API)

- URL: https://www.data.go.kr/data/15061491/openapi.do
- 운영 주체: 대구광역시 (담당 청년정책과로 표시)
- 대상/자격: 대구 지역 여러 기관 강좌. 강좌별 상이(미확인)
- 비용: 강좌별 상이(미확인). API 이용은 무료
- 지역: 대구 오프라인 중심
- AI 관련 강좌 예시: API 응답에서 직접 확인 못함(미확인). 참고로 2026년 하반기 대구시민대학(10/1~12/4, 26개 강좌) 기획강의에 AI 분야 포함, 대구시교육청 공공도서관 10곳 하반기 190개 프로그램에 AI·유튜브 제작 포함(언론 보도)
- 갱신 주기: **실시간**(메타데이터 표기)
- 데이터 수집: **Open API**(REST, XML). 서비스키 필요. 개발계정 트래픽 1,800건, 활용사례 등록 시 증량. 응답 필드·엔드포인트는 가이드 zip에만 있어 미확인
- 제약: 활용신청 필요. 트래픽 1,800/일(개발) 제한
- 서비스 우선순위: **중** — 시도 포털 중 API가 공식 제공되는 사례. 대구 사용자용 보강. 전국 표준데이터와 중복 여부 확인 필요
- 확인일 / 출처: 2026-10-11 / https://www.data.go.kr/data/15061491/openapi.do, https://kbmaeil.com/article/20260907500319, https://www.kbmaeil.com/article/20260804500512
