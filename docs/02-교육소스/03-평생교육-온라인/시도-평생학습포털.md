# 시도 평생학습포털 · 지역 평생학습관 · 대학 평생교육원

- 작성일: 2026-10-11
- 상위: [00-START-HERE.md](00-START-HERE.md)

시도 포털은 온라인 강좌(대부분 전 국민 수강 가능)와 해당 시도 오프라인 강좌를 함께 싣는다. 시군구 평생학습관·주민센터 강좌는 사이트가 수백 개로 흩어져 있어 [전국평생학습강좌표준데이터](평생학습강좌-표준데이터.md)로 받는 편이 낫다.

### 서울시평생학습포털 (서울런 평생학습)

- URL: https://sll.seoul.go.kr
- 운영 주체: 서울특별시 (하단 유관기관 서울시평생교육진흥원 링크, 학습지원센터 1599-3665). 운영 주체 명시 문구는 페이지에 없음
- 대상/자격: 온라인은 회원 누구나로 추정(미확인), 오프라인은 서울시민 위주(강좌별)
- 비용: 대부분 무료로 추정(미확인). 강좌별 표기 확인 필요
- 지역: 온라인(전국) + 서울 오프라인(25개 자치구 필터 있음)
- AI 관련 강좌 예시 (메인 노출, 2026-10-11 확인):
  - 온라인 「[AX의 정석-분석편] 감만 믿던 직장인, AI로 노코드 데이터 분석 시작하기」
  - 온라인 「[ChatGPT] 영업제안서 10분만에 생성하고 칼퇴하기」
  - 오프라인 「퇴근 없는 디지털 부업! 생성형 AI활용 유튜브 쇼츠 크리에이터 양성과정」 ← N잡 카테고리와 정확히 맞음
  - 오프라인 「AI 영화음악 워크숍」, 「AI로 만드는 나만의 음원 <음악 프로듀서 원데이 클래스>」
- 갱신 주기: 상시(온라인), 오프라인·특강은 수시
- 데이터 수집: **목록 크롤링**. 공식 Open API 못 찾음(서울 열린데이터광장에도 미확인)
  - 온라인 분야별: `/lms/requestCourse/doListView.do?main_se=lie&course_category_id=…` (분야에 '디지털/AI' 카테고리 존재)
  - 생애주기별: `/lms/requestCourse/doAgeCourseListView.do?keyword=중장년` 등
  - 외부기관 연계: `/lms/front/externalapi/doListView.do`
  - 특강정보: `/lms/Mongttang/doListView.do?page_gubun=seoulCourseInfo`
- 제약: robots.txt는 Googlebot에 대해 `/search/doSearchView.do`, `/search/doSearchDetailView.do`만 차단. 목록 경로는 차단 없음. 약관 미확인
- 서비스 우선순위: **상** — 서울 사용자 비중이 크고 '디지털/AI' 분야가 따로 있으며, 실제로 N잡형 AI 강좌가 올라온다
- 확인일 / 출처: 2026-10-11 / https://sll.seoul.go.kr, https://sll.seoul.go.kr/robots.txt

### 경기도평생학습포털 지식(GSEEK)

- URL: https://www.gseek.kr
- 운영 주체: 경기도 (저작권 표기 © GYEONGGI PROVINCE, 패밀리사이트 경기도평생교육진흥원). 2016년 경기도평생교육진흥원·여성능력개발센터·인재개발원 등의 e러닝을 통합해 개설
- 대상/자격: 미확인 (경기도민 한정 여부 페이지에 없음)
- 비용: 미확인 (무료로 알려짐, 공식 확인 못함)
- 지역: 온라인 + 경기 오프라인(지역별 필터 `isLocal=Y`) + 화상학습
- AI 관련 강좌 예시: 메인에서 확인 못함(미확인). 분야에 '디지털역량', '컴퓨터활용', '취업/창업'이 있음
- 갱신 주기: 상시
- 데이터 수집: **목록 크롤링**
  - `/user/course/online/list`, `/user/course/offline/list`, `/user/course/video/list`
  - 필터: `?isRecru=Y`(모집 중), `?isLocal=Y`(지역별), `?isbiz=Y`(기관별), `?s_sbjct_clsf_sn={분야ID}`
- 제약: **2026-10-11 현재 플랫폼 개편 테스트 중**이라 회원가입·수강신청·수료증 발급 중단 안내. 개편 후 URL 구조 바뀔 수 있음. robots.txt는 `/user/join`, `/user/mypage/`, `/user/search`, 강의실, 강의 목록 검색 AJAX 등 차단, 나머지 `Allow: /`
- 서비스 우선순위: **중** — 경기도 규모는 크지만 개편 중이라 구조 확정 후 붙이는 게 맞다
- 확인일 / 출처: 2026-10-11 / https://www.gseek.kr, https://www.gseek.kr/robots.txt, https://magazine.hankyung.com/business/article/201611089499b

### 부산 (부산여성가족과평생교육진흥원)

- URL: 미확인 (부산 시 단위 평생학습 강좌 포털 주소를 검색으로 찾지 못함)
- 운영 주체: 부산여성가족과평생교육진흥원
- 대상/자격·비용: 미확인
- 지역: 부산
- AI 관련 강좌 예시: 시민 대상 AI 강좌 미확인. 진흥원이 'AI·디지털 조력자 2.0' 과정을 운영했으나 대상은 성인문해교육 강사 50명(일반 시민 아님)
- 갱신 주기: 미확인
- 데이터 수집: 표준데이터로 부산 시군구 강좌 커버 기대. 별도 포털은 미확인
- 서비스 우선순위: **하(보류)** — 포털 확인 후 재평가
- 확인일 / 출처: 2026-10-11 / https://www.busan.com/newsinnews/bgli

### 대구

- 대구광역시 평생학습포털은 data.go.kr에 **강좌조회 Open API**가 있다 → [평생학습강좌-표준데이터.md](평생학습강좌-표준데이터.md#대구광역시_평생학습포털_강좌조회서비스-open-api)
- 기관명이 대구평생교육진흥원 → 대구평생학습진흥원(별도 법인) / 대구행복진흥원 등으로 보도마다 다름. 현재 명칭 미확인

### 기타 시도

- 인천·광주·대전·울산·강원 등 나머지 시도 포털은 이번에 확인 못함(미확인). 시군구 강좌는 표준데이터로 받고, 시도 포털은 온라인 강좌가 많은 곳만 골라 2차로 붙이는 걸 권장

### 시군구 평생학습관 · 주민센터 · 공공도서관 강좌

- URL: 기관별 (예: 성동구 평생학습관 = 구청 누리집)
- 운영 주체: 시군구, 교육청(공공도서관)
- 대상/자격: 대개 해당 시군구 거주·재직자 우선, 선착순
- 비용: 무료 또는 저가(재료비 별도) 많음
- 지역: 시군구 오프라인
- AI 관련 강좌 예시:
  - 성동구 평생학습관 'AI 시대, 든든한 내 업무 비서 만들기(챗봇)' — 2026년 3분기, 7/20~8/31 대면, 무료(재료비 별도), 구청 누리집 선착순 접수
  - 동두천시 평생학습관 '생성형AI 활용 실전-기초'(2025, 텍스트·이미지·음악·영상 생성 실습)
  - 대구시교육청 공공도서관 하반기 프로그램에 AI·유튜브 콘텐츠 제작 포함(2026)
- 갱신 주기: 분기별 정기강좌가 흔함
- 데이터 수집: **전국평생학습강좌표준데이터 API**(1순위). 개별 크롤링은 사이트 수가 너무 많아 비현실적
- 제약: 표준데이터 등록이 누락된 기관이 있을 수 있음, 월~분기 지연
- 서비스 우선순위: **상** — "우리 동네 무료 AI 강좌"가 서비스 핵심 가치. 수집은 표준데이터로 해결
- 확인일 / 출처: 2026-10-11 / https://sports.khan.co.kr/article/202606282359003, https://www.kbmaeil.com/article/20260804500512

### 대학 평생교육원 (미래교육원 등)

- URL: 대학별 (예: 서강대 미래교육원 https://scec.sogang.ac.kr)
- 운영 주체: 각 대학
- 대상/자격: 성인 누구나(대부분)
- 비용: **유료**(자부담) 대부분. 서강대 'AI 콘텐츠제작 전문가과정' 수강료는 미확인
- 지역: 대학 소재지 오프라인(일부 온라인)
- AI 관련 강좌 예시:
  - 서강대 미래교육원 「AI 콘텐츠제작 전문가과정」 — 텍스트→이미지, AI 영상 합성, AI 3D 모델링, SNS 콘텐츠·영상 제작
  - 한성대 학점은행 'AI콘텐츠창작(AI 콘텐츠 크리에이터)' 전공 — 학위 과정이라 단기 강좌 아님
  - 인하대 평생교육원 인천시민대학(2026-1학기 모집) — AI 과목 여부 미확인
- 갱신 주기: 학기(분기) 모집
- 데이터 수집: 수동 또는 대학별 크롤링. 일부 강좌는 표준데이터나 온국민평생배움터에 연계될 가능성(미확인)
- 제약: 대학마다 사이트 구조가 다름
- 서비스 우선순위: **하** — 유료·학기제라 무료 매칭 서비스 초기 범위와 안 맞는다. 상위 몇 개 대학만 수동 등록 검토
